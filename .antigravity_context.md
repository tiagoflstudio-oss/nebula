# 📌 Contexto do Projeto: Nebula (Mestre Clientes)

Este projeto segue o ecossistema de criação Mestre Clientes supervisionado pelo PicoClaw.

## 🛠️ Stack Tecnológico
- **Frontend**: React 18, Vite, CSS Vanilla (Glassmorphism, Dark Theme)
- **Backend/DB**: Supabase (PostgreSQL, Auth)
- **Proxy Local**: Node.js (`nebula-bridge.js` rodando na porta 3001)

## 🏗️ Padrões de Arquitetura & Diretórios
- `src/pages/`: Componentes de páginas em formato Lazy Loading (ex: `App.jsx` com `Suspense`).
- `src/components/`: Componentes visuais isolados (ex: `QuotaCard`).
- `src/services/`: Toda a lógica de comunicação externa (ex: `quotaService.js`, `oauthService.js`).
- **Design System**: Não utilizamos Tailwind. Estilo base puramente em `index.css` e `.css` modulares seguindo padrão *Glassmorphism*.

## ⚠️ Restrições e Regras Cruciais
1. **NUNCA apague regras do PicoClaw**: Siga estritamente as hierarquias.
2. **Uso do Bridge Local**: Para APIs que bloqueiam CORS (ex: Google OAuth e gcloud cli), SEMPRE passe pela `nebula-bridge.js`.
3. **Erros Silenciosos**: Toda requisição para `nebula-bridge` ou Supabase deve possuir `try/catch` para não travar a UI de forma fatal.

## 📜 Histórico e Decisões Recentes
- Implementado proxy local (`npm run bridge`) para desviar do CORS das requisições de cota.
- Adicionado sistema de fallback para token ADC local via comando `gcloud auth print-access-token` no `quotaService.js` (Rota `/api/antigravity/refresh-local-token`).
- Performance melhorada usando Code Splitting em `App.jsx`.
